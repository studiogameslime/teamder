# בדיקות סטטיסטיקה מול מסד מקומי

הרצה משורש המאגר:

```powershell
node tests/integration/run-statistics-firestore.cjs
```

נדרשים Java 21 ומעלה, תלויות המאגר/פונקציות, וקובץ אמולטור שמור ב־`.cache/firebase/emulators/cloud-firestore-emulator-v1.22.0.jar` בתיקיית המשתמש. אפשר לתת נתיב אחר באמצעות `TEAMDER_FIRESTORE_EMULATOR_JAR`. הכלי אינו מוריד תוכנה. הוא בונה פונקציות מקומית, מסרב לתפוס שירות קיים בפורט 8185, מפעיל מסד על `127.0.0.1` עם יעד קבוע `demo-teamder-night-audit`, ומפסיק את התהליך שיצר גם כשהבדיקה נכשלת. אין פריסה, ייצוא/ייבוא, חשבונות אימות או גישה למסד ייצור.

`seasonRollover.firestore.cjs` מפעיל את `closeSeason/reopenSeason` שנבנו מקוד המאגר, מול אצוות ועסקאות Firestore אמיתיות באמולטור. הוא בודק ארכוב, כשל בחמישה שלבים, שחזור, תרומה שהגיעה באמצע, סגירות מקבילות, מטא־נתונים קפואים, שתי סגירות/פתיחות מחדש ו־401 צמדים עם דף ארכיון חסר. מסמכי הבדיקה סינתטיים ומזוהים לפי הרצה; אין יצירת מועדון או חשבון דרך האפליקציה.

`retroGoals.firestore.cjs` מחלץ את גופי מטפלי ההשלמות והפעילות והתלויות המקומיות האמיתיות מתוך `functions/src/index.ts`, ומשתמש בבודק העונה האמיתי. רק מעטפת `onCall` מוחלפת כדי להזין בקשה ישירות. כך נבדקים מניעת כפילות, היפוך, כשל אצווה, תחרות מול שינוי עונה ושמירת מרב מדדי פעילות בעסקאות אמיתיות. ה־`auth.uid` מוזרק; **אין כאן אימות אסימון, App Check, תעבורה לפונקציה פרוסה, כללי הרשאות לקוח או בדיקת מסירת פוש**.

יומני הריצה, בניית הפונקציות, האמולטור וחותמות מקורות הקוד נמצאים ב־`artifacts/night-eighth-*`. בדיקות אלו רצות ב־`node:test` בנפרד מחבילת Jest; אין להציג את מונה Jest כאילו הוא כולל אותן.

לבדיקת המעבר החיצוני וסריקת העונות:

```powershell
node tests/integration/run-statistics-firestore.cjs --lifecycle
```

מצב זה משתמש ביעד נפרד וקבוע `demo-teamder-season-lifecycle` וביומני `artifacts/night-ninth-*`. הקובץ `seasonLifecycle.firestore.cjs` מחלץ את גופי `performSeasonClose`, `closeSeasonIfRoundsTargetMet`, `runSeasonRollovers` ותלויותיהם המקומיות מהמקור הנוכחי. הארכוב, הנעילה, העסקאות וחישובי התאריך מופעלים מהקוד האמיתי. רק מסירת ההודעה ודיווח השגיאה מוחלפים: האישור המדומה מעדכן את תור ההודעות המקומי, ולא שולח דבר. השעון מוזרק לגופי המעבר; מנגנון העסקאות עצמו משתמש בשעון המחשב. נבדקים 17 תרחישים, כולל סריקה של 201 מסמכים, הגבלת חמש סגירות, חלונות 24/48 שעות, חסימת מחזור פעיל או סיכום חסר, התחרות והתאוששות. אין בדיקת הגעת אירוע מתזמן בענן או הגעת הודעה למכשיר.
