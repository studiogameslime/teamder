# כניסה מאובטחת לפולס

פולס מיועד לחשבונות מנהל שאושרו מראש. נכנסים בחשבון קיים באמצעות גוגל או דואר וסיסמה. אין יצירת משתמש חדש במסך זה.

מפתחות הניהול נשמרים בשרת ואינם מועברים לטלפון. ההתחברות השמורה מוגנת באחסון המכשיר ומוחרגת מגיבוי למכשיר אחר. אפשר להתנתק מההגדרות.

השינוי הוכן מקומית בלבד. נדרשות הגדרת חשבונות מורשים, פריסת שרת, בדיקת כניסה ובנייה חדשה. המפתחות הישנים טרם בוטלו והגרסה הקיימת עדיין דורשת טיפול במעבר.
