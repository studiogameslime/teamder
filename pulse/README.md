# פולס

יישום הניטור של טימדר. הקוד נשמר כאן כפרויקט עצמאי, עם תלויות והגדרות בנייה משלו.

הועתק מהקוד המקומי ב־`~/Projects/pulse` ב־8.10.2026, כולל השינויים המקומיים. התיקייה המקורית נשארה ללא שינוי. זו תמונת מצב; שינויים עתידיים בתיקייה המקורית אינם מסתנכרנים אוטומטית.

להתקנת התלויות ולהרצה:

```sh
cd pulse
npm ci
npm start
```

הכניסה מתבצעת בחשבון קיים ומורשה בלבד, דרך שרת הניהול. מפתחות שירות אינם נכללים ביישום. נדרשים מזהה לקוח ציבורי ומפתח תצורה ציבורי במשתני `EXPO_PUBLIC_PULSE_GOOGLE_WEB_CLIENT_ID` ו־`EXPO_PUBLIC_PULSE_FIREBASE_API_KEY`; ההרשאה עצמה נקבעת בשרת. הקובץ הישן `src/secrets.ts` אינו נצרך ואינו נכלל בחבילת ההפצה. נדרשת בנייה מקומית חדשה עקב רכיבי האחסון המוצפן והכניסה. השרת נפרס באישור ונבנה פולס `1.0.93 / 100`. שני המנהלים אושרו; המפתחות הישנים לא בוטלו. כניסה אמיתית טרם אומתה.

התיקייה אינה חלק מבדיקת הטיפוסים או מאריזת היישום הראשי. הוראות העבודה של פולס מופיעות ב־`AGENTS.md` שבתיקייה זו.
