# הפצת 1.1.71

הבעלים אישר ב-2.11.2026 לשמור ולדחוף את כל העבודה למאגר ולהעלות גרסה לייצור בגוגל ובאפל. ההפצה כוללת את הלקוח הנוכחי, תיקוני הפולס ותלויות השרת. אישור זה אינו כולל הסבת נתונים, מחיקת נתונים או הפצת יישום הפולס עצמו.

`firestore.compat.rules` נגזר מכללי הייצור שנקראו ב-2.11.2026. נוספו בו כללי בקשות השיחה, הגנה על חברות ועל בחירת הפרטיות, והסרת תקרת 500 חברים בענף המנהל. נשמרו קריאות הסגלים, חיפוש הזהויות, הצטרפות המועדונים ומקור דירוגי המנהלים של הלקוחות הישנים. זהו קובץ מלא לבדיקה ולפריסה, ולא קובץ כללים מצומצם. `firestore.rules` שבשורש ממשיך לתאר את המדיניות הסופית המחמירה.

נעילת מסמכי המשתמשים והדירוגים המלאה אינה חלק משלב התאימות. נוהל ההפצה מחייב לתאם אותה עם עדכון הלקוחות הישנים. הבעלים אישר לחייב עדכון ולהשלים את נעילת הפרטיות לאחר ש-1.1.71 זמינה בשתי החנויות. עד לאימות שני התנאים אין להפעיל את הנעילה. שירותי הדירוג ימשיכו להשתמש בדגל התאימות הקיים; אין העברת נתונים למקור פרטי או הסבה במשימה זו.

גרסת המקור המיועדת היא 1.1.71. לפני הבנייה נדרשים טיפוסים נקיים, מלוא בדיקות היישום, מלוא בדיקות הכללים בסדרה ובדיקות שירותי החברים ובקשות השיחה במסד מקומי. יש לאמת את חותמת המקור של כל תוצר מול השמירה במאגר, להעלות תחילה למסלול הפנימי בגוגל ואז לקדם לייצור. באפל נדרשת הגשה לבדיקת החנות ושחרור לאחר אישור.

תוצאות וגבולות האימות יירשמו ב-`docs/changes/2026-11-02-production-1.1.71.md`. מסמכי הראיות הפרטיים, מפתחות החתימה ותוצרי הבנייה נשארים בתיקייה המקומית `artifacts/release-2026-11-02` ואינם חלק מהמאגר.
