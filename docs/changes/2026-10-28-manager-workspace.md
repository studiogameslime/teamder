# הרחבת לוח המנהל - 28.10.2026

עדכון הפצה מאוחר יותר באותו יום: לוח המנהל נכלל בגרסה הפנימית `1.1.68/301`, ושני שירותי ההיסטוריה נפרסו ואומתו. יתר התיאור להלן מתעד את שלב המימוש המקומי שקדם להפצה. [אימות ההפצה ומגבלותיו](2026-10-28-internal-1.1.68.md).

מומש מקומית בעקבות אישור הבעלים לסקיצות. לא בוצעו פריסה, בנייה לחנויות, שינוי הרשאות, הסבת נתונים, שמירת קוד במערכת ניהול הגרסאות או דחיפה לשרת קוד.

## מה השתנה

נוספו דפי פירוט בתוך מסך המנהל הקיים: מוכנות למחזור, סגל, מידע ניהולי לשחקן, חדשים, פעילות, עונה, ביקוש, ביטולים והגעה והמשכיות. הסקירה מדרגת נושאים לטיפול ומציגה שניים לפני הרחבה. לשונית הציוד מציגה תחילה מחזיקים נוכחיים מול הרשמה עתידית. הגרף משתמש בטווח אחיד של 0 עד 10. נשמרו שלוש הלשוניות, ספי 7 מתוך 10 והניווט בארבע המחסניות.

הוכנה שכבת שרת עצמאית לאיסוף היסטוריית הרשמה עם קבלה אידמפוטנטית, סדר לפי זמן המקור ושער ניהול קנוני כפול. מדדים מלאים נבנים רק אחרי תחילת איסוף מספקת, ללא המצאת היסטוריה למחזורים קיימים. שני השירותים החדשים הם onManagerRoundChanged ו-getManagerRoundHistory, והם טרם נפרסו.
