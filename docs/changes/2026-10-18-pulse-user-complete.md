# הרחבת כרטיס המשתמש הקיים

לפי בקשת הבעלים, כרטיס משתמש אחד מרכז פרופיל, פעילות ותמיכה, קשרים ומחזורים, מכשירים וניהול. פרטי נתונים שלא הוצגו נשמרים במיפוי ונגישים בסעיפים מתקפלים. קריאות קיימות משותפות לתצוגות החדשות; מקורות נוספים נטענים לפי צורך. צילומי דיווחים ויומנים כבדים אינם נכללים עוד בתשובת הרשימות בכרטיס.

[התנהגות ומקורות](../features/shared/pulse-management.md), [הסבר פשוט](../features/shared/pulse-management.simple.md), [ראיות](../audits/evidence/pulse-user-complete/README.md).

הוכנה גם סקיצת איכות גרסה, עם נתוני הדגמה בלבד; המסך המוצע לא מומש במשימה הזו.
