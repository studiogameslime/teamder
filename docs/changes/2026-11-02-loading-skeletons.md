# שלדי טעינה בבית, בסגל ובנתוני המועדון

מימוש מקומי מ-2.11.2026. לא בוצעו בנייה, שמירה בגיט, פריסה או העלאה לחנויות.

בבית נוספו שלד לכרטיס המחזור ושלד לכרטיס הנתונים האישיים. בסגל מוצגים מקומות לחיפוש, לסינון ולשחקנים; בנתוני המועדון מוצגים מקומות למדדים ולטבלה. תוכן זמין אינו ממתין לסיום אנימציה. ברענון נשאר מידע שכבר הגיע לאותו הקשר.

## מצבים ומסלול הנתונים

| מצב | התנהגות |
|---|---|
| טעינה ראשונה בבית ללא כרטיס מחזור | `HomeRoundSkeleton`; כשל מציג ניסיון חוזר דרך `gamesRetry` |
| נתונים אישיים ראשונים | `PersonalStatsSkeleton` בתוך מסגרת הכרטיס הקיימת |
| טעינת סגל ראשונה | `PlayersSkeleton` עד שמסמך המועדון ושמות חבריו מוכנים יחד |
| רענון סגל | הרשימה נשארת עם הודעת עדכון קטנה; כשל משאיר אותה ומציג ניסיון חוזר |
| מועדון או חשבון אחרים בסגל | התשובה הישנה מוסתרת מיד; תשובות מדור קודם נזרקות |
| טעינת נתוני מועדון | `ClubStatsSkeleton` לפי תנאי `bootLoading` הקיים |
| רענון נתוני מועדון | מידע קיים נשאר; חיווי עדכון קטן נוסף |
| יותר מארבע שניות | הכיתוב מתחלף פעם אחת להסבר שהמידע עדיין נטען; אין אחוז מדומה |
| צמצום תנועה | הפעימה מבוטלת; הצורות נשארות סטטיות |
| סיום או עזיבה | ביטול הפעימה, ניקוי שעון ההודעה והתעלמות מתשובת סגל מאוחרת |

`src/hooks/useCommunityRoster.ts` מרכז את אותן קריאות סגל שהיו במסך, עם שמירת תשובה אטומית לפי מועדון, צופה ומצב אורח. גם קריאה שמופעלת דרך פעולה שהסתיימה אחרי מעבר או עזיבה נחסמת לפני תחילת טעינה, כדי שלא תבטל את הבקשה החדשה. אין כתיבה חדשה במסד, שינוי בהרשאות או שינוי בחישובי השתתפות, כרטיסים, תוצאות ועונות. כשל בהעשרה אופציונלית נשאר עם החלופה הקיימת; כשל בטעינת המועדון או האנשים אינו תשובה ריקה תקינה.

`src/components/loading/ScreenSkeletons.tsx` מפעיל פעימה אחת לכל אזור, על תהליכון הממשק. השקיפות נעה בין 1 ל-0.55 במשך 1,100 אלפיות שנייה בכל כיוון. `useReducedMotion` מפסיק אותה. הצורות מוסתרות משירות הנגישות; הודעת האזור היא חיווי טעינה עם הכרזה מנומסת.

## צילומים ומגבלות

הצילומים מבוססים על אזורי טעינה מתוך הקוד האמיתי, עם מתאמי רכיבים מפורשים ומסגרת מקומית. סמל הכדור המקורי הוחלף בתצוגת הדפדפן. האנימציה אינה פועלת בתצוגה הסטטית. נבדקו חזותית הסדר מימין לשמאל, המקומות לתוכן והיעדר גלילה אופקית ברוחבי 320, 390 ו-430 נקודות. שלושת הצילומים שלפני השינוי נלקחו לפני עריכת קוד המוצר.

## בדיקות

עשר בדיקות ממוקדות ב-`tests/logic/communityRosterLoading.test.ts` עברו. הן מפעילות את קוד הטעינה המקורי עם תשובות נשלטות: המתנה לאנשים, רענון וכשל, כשל ראשון וניסיון חוזר, מועדון חסר, מעבר מועדון וחשבון, שינוי מצב אורח, שתי קריאות בסדר הפוך, ניקוי בעזיבה, נתונים אופציונליים והרשאת קריאת כרטיסים. נבדקו גם שעון ההמתנה, ניקויו והפסקת הפעימה בצמצום תנועה. אלה בדיקות קוד, ולא אימות חזותי או מסד חי.

בדיקת הטיפוסים עברה, וכל 6,548 הבדיקות ב-586 חבילות עברו אחרי שינוי הקוד האחרון. הפקודות שהורצו הן `node node_modules/typescript/bin/tsc --noEmit` ו-`node node_modules/jest/bin/jest.js --runInBand --cacheDirectory=artifacts/loading-skeletons-2026-11-02/jest-cache`, משום שהמעטפת המקוצרת אינה זמינה בתהליך. היומנים הם `typecheck-final.log` ו-`jest-verified.log` בתיקיית הראיות. חותמות שמונת קובצי המקור והבדיקה נשמרו לפני האימות הסופי ונבדקו שוב ללא שינוי.

בהרצה הראשונה בדיקת זהות ישנה חיפשה את טעינת הסגל במסך עצמו, ושבע בדיקות של מעטפת הבנייה נחסמו בסביבת ההרצה המצומצמת. הבדיקה הותאמה לרכיב המשותף תוך שימור תרחישי הזהות והגישה; בדיקות המעטפת עברו בהרצה המקומית המורשית. לאחר מכן נוספה ונבדקה גם חסימת קריאה שמורה אחרי מעבר או עזיבה, וכל החבילה הורצה מחדש.

עודכנו ורועננו 16 זוגות תיעוד, כולל השפעת המקורות והבדיקה המשותפים, ונשמרו שש תמונות במניפסט. בדיקת התיעוד הכללית הורצה ונשארה עם 127 רשומות כשל קודמות, ובהן 20 פערי מצב בתחומים אחרים וקישורים לקובצי ראיות היסטוריים שאינם במחשב הזה. ההשוואה למקור בגיט ולמצב לפני המשימה לא מצאה כשל חדש; כרטיסי השינוי הנוכחי מעודכנים. אין לטעון שבדיקת התיעוד הכללית נקייה. הקבלות הן `docs-receipt.json` ו-`status-receipt.json` בתיקיית הראיות.
