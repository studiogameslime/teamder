[הוראות הניהול והמסירה לדוט](dot-management.md) מגדירות את חלוקת העבודה ואת גבולות האישור. ההוראות הוכנו מקומית; אין לטעון שהן נקלטו אצל דוט או שולבו בפרסום לפני אימות ישיר. הטיוטה הראשונה הושלמה: [תוכן למארגנים](organizers-launch-draft.md).
