# Teamder — מדריך לאפיון עיצובים

מסמך אחד שמלמד על האפליקציה כפי שהיא **היום**: מה היא עושה, איך היא בנויה,
באילו מילים היא מדברת, ובאילו כללים היא מציירת.

**גרסה מתועדת:** 1.1.26 · 30.09.2026 · אנדרואיד ו-iOS · עברית מלאה, RTL.
כל צילומי המסך בתיקייה `02-צילומי-מסך` צולמו מהבילד הזה.

## 1. מה האפליקציה עושה

Teamder מארגנת כדורגל חובבים. לא ליגה ולא טורניר — **הערב השבועי הקבוע**
של קבוצת חברים: מי מגיע, איך מחלקים כוחות, מה קרה במגרש, ומי הכי טוב בעונה.

שני סוגי משתמשים:

| | |
|---|---|
| **מארגן / מנהל מועדון** | פותח מחזורים, מחלק כוחות, מנהל את ההרכב, סוגר עונות |
| **שחקן** | נרשם למחזור, רואה את הכוחות, רואה את הסטטיסטיקות שלו |

המוצר מתוכנן **קודם כל למועדון קבוע**, ורק אחר כך למשחק חד-פעמי.

⚠️ **אין ולא יהיה שום דבר שקשור לכסף.** לא קופה, לא דמי חבר, לא חלוקת
תשלום, לא חסויות. אל תציע פיצ'רים כאלה.

## 3. מבנה הניווט

ארבעה טאבים בתחתית:

```
בית · מועדונים · מחזורים · צ'אטים
```

המסך המרכזי של המוצר הוא **פרטי מחזור**, ואליו מגיעים מכל מקום.

### פרטי מחזור — ארבעה טאבים תחת כותרת אחת

הסדר מימין לשמאל: **מידע · שחקנים · משחקים · סטטיסטיקות**

| טאב | מה יש בו |
|---|---|
| **מידע** | כרטיס הכוונה לכוחות · הודעת מארגן · פרטי המחזור (מיקום, פורמט, מועדון, מארגן, משך, מזג אוויר) · ניווט ל-Waze · חוקי המועדון |
| **שחקנים** | הכוחות שחולקו + ייצוא לוואטסאפ · מוני רשומים/בהמתנה · הוסף אורח · ההרכב המלא (דירוג, תפריט, שעת הרשמה) · רשימת המתנה · ביטולי השתתפות |
| **משחקים** | כל המשחקונים שנרשמו, עם מסנן לפי צבע קבוצה |
| **סטטיסטיקות** | סיכום אישי · המחזור במספרים · כוכבי המחזור · הקבוצות · הצמד · מה קרה הערב · טבלת המחזור |

**שני הטאבים הימניים תמיד פתוחים. שני השמאליים נעולים** כשהמחזור לא במצב
משחק מורחב, או כשהצופה אינו חבר במועדון. טאב נעול נשאר גלוי עם מנעול
ומסביר את עצמו בלחיצה — הוא לא נעלם.

**התמונה נגללת החוצה, סרגל הטאבים נשאר נעוץ למעלה.** ראה צילום 11.

## 4. כללי RTL — קרא את זה לפני שאתה מאפיין פריסה

האפליקציה רצה תחת `I18nManager.forceRTL`. שני כללים שלא אינטואיטיביים:

### א. `flexDirection: 'row'` כבר מתהפך

**הילד הראשון בקוד מופיע הכי ימני במסך.**

```
<Ionicons/>  <Text/>        ←  אייקון מימין, טקסט משמאלו   ✅ הנוהג שלנו
<Text/>  <Ionicons/>        ←  טקסט מימין, אייקון משמאל
```

אל תשתמש ב-`row-reverse` כדי "לתקן" — זה הופך פעמיים.

### ב. `textAlign: 'right'` נותן יישור שמאלה

תחת forceRTL המערכת מחליפה right↔left. לכן בקוד כתוב `'left'`, ובמסך
הטקסט יוצא **מיושר לימין**. יש טוקן לזה:

```ts
import { RTL_LABEL_ALIGN } from '@/theme';   // = 'left'
textAlign: RTL_LABEL_ALIGN                    // → נראה ימני
```

**אל תוסיף `writingDirection: 'rtl'` לתוויות** — זה מפעיל את אותה החלפה
פעם שנייה.

### ג. מספרים בתוך עברית מתהפכים

`15/15` בתוך פסקה עברית ייקרא `15/15` הפוך. הפתרון: תו LRM לפני המספר.

```ts
`‎${value}`      // "16/15" נשאר "16/15"
```

זה נדרש לכל דבר שהוא מספר-עם-מפריד: תוצאות `2:1`, יחסים `15/15`,
אחוזים, ותוספות כמו `+2`.

## 6. דפוסים חוזרים

**כרטיס מידע** — רקע לבן, פינות 14–16, ריפוד `lg`, צל עדין.

**צ'יפ / פילטר** — גלולה (`borderRadius: 999`), רקע `primaryLight`
כשפעיל, מסגרת דקה כשלא.

**מצב ריק** — אייקון קווי גדול, כותרת, ומשפט הסבר. **תמיד תגיד למה ריק**,
ואל תשקר: מחזור שעוד לא שוחק ומחזור היסטורי בלי נתונים הם שני מצבים
שונים עם שני נוסחים שונים.

**סקציה שמוסתרת כשהיא ריקה** — אין סקציות ריקות ואין "—" כממלא מקום.

**כותרת סקציה** — אייקון ראשון בקוד (יוצא ימני), טקסט לידו.

**באנר ענבר** `#FEF3C7` עם טקסט `#B45309` — הערות על המחזור
(חוקי מועדון, הכוונה לכוחות).

שהמשתמש רואה נמצאת שם, עם הערות שמסבירות למה כל אחת נוסחה כך. אם אתה
מאפיין מסך — חפש שם את המילים הקיימות במקום להמציא חדשות.
