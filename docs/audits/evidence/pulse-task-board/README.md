# לוח משימות ומסירה על ידי רובנס

ארבע תצוגות בלוח אחד, פירוט במסך מלא, תמונת המקור והוכחת תיקון בנפרד, והוראות סיום קבועות בפרויקט. שדות המסירה המקוריים נשמרו לתאימות. הוסרו קישורי רשימות האבחון והרעיונות; מסלולים ישנים פותחים את הלוח. אין הרשאות חדשות, פריסה או בנייה.

צילומי הדפדפן משתמשים ברכיבים האמיתיים ובנתוני הדגמה. 12 מצבים ברוחבי 320 ו־390 עברו ללא שגיאות ריצה או גלישה אופקית. נבדקו ארבע התצוגות ופירוט עם צילום וסיכום, פתיחה וחזרה. הסמלים הוחלפו; מחוות הגדלת צילום ומקלדת במכשיר אמיתי לא אומתו. בדיקות הלוגיקה מאמתות גם קריאת תמונת דיווח המקור וכשלי קריאה.

`versions-concept.png` היא סקיצה שנוצרה באמצעות כלי יצירת תמונות, עם נתוני הדגמה. זו הצעה למסך הגרסאות ולא קוד שהוטמע. צילומי `pulse-board-*` הם רינדור של קוד הלוח שהשתנה.

מסירת המשימה ויומן השחרור מוכנים בקבצים מקומיים בלבד. אין בסביבה חיבור ניהול מאומת או מזהה פריט למשימת השיחה הזו, ולכן לא נטען שנכתב סטטוס לייצור.

בדיקות הטיפוסים של שני היישומים עברו. כל 425 חבילות הבדיקה ו־5,001 הבדיקות עברו. בדיקת התיעוד מצאה 107 קישורים חסרים קיימים, ללא תקלות חדשות ביחס לסבב הקודם.
