# כרטיס המשתמש המאוחד — ראיות מ־18.10.2026

הכרטיס הקיים הורחב; לא נוסף מסך תמיכה נפרד. [תיעוד נתונים, מקורות ומגבלות](../../../features/shared/pulse-management.md#כרטיס-משתמש-מאוחד--השלמה-ב־18102026).

הרינדור משתמש ב־React Native Web, בקוד TSX של המסך ובנתוני הדגמה מקומיים. סמלים מוחלפים בעיגולים, אזורים בטוחים מאופסים, והרשת החיצונית חסומה. לא בוצעו שליחה, שינוי סטטוס, מחיקה או שינוי סימון בודק. קובצי הבנייה והצילום ניתנים להרצה באותה סביבת `/tmp/pulse-preview` שהוגדרה בראיות הסבבים הקודמים, עם שרת מקומי על 8765 ו־Chromium.

`user-results.json` מתעד את המצבים והרוחבים. נבדק שאין קריאות למקורות הנוספים בפתיחת הפרופיל, שיש קריאה אחת בפתיחת ההתראות, ושחזרה ללשונית אינה קוראת שוב. נבדק גם שהאסימון המדומה אינו מופיע בתצוגת פרטי המכשירים. הצילומים נבדקו חזותית, לרבות פרופיל, פרטי חשבון, קשרים וניהול.

במסד המדומה נשמר מידע עשיר להמחשה; בדיקות השירות נפרדות ואינן עוקפות את מיפוי `fetchUserActivity`, `mapAuthRecord` או `userRecord`. הבדיקות לא מוכיחות זמינות של מידע זה לכל משתמש אמיתי.

הסנכרון המפורש של נתוני ההתחברות הוא פעולה רחבה דרך נקודת הגישה שכבר מותרת. שאר המקורות מסוננים למזהה המשתמש ומוגבלים, עם מטמון. לא שונתה מדיניות גישה כדי להוסיף חיפוש חשבון בודד.

סקיצת איכות הגרסה נשמרת בנפרד כקונספט עם נתונים להמחשה. היא אינה צילום של מסך ממומש ואינה חלק מהוכחות הרינדור.

מגבלות: לא נבנה או הותקן עדכון, לא נמדדו קריאות ייצור, ולא נבדקו מקלדת ומחוות במכשיר אמיתי. יומן השחרור המרוחק לא עודכן ללא חיבור ניהול מאומת; הוכנה רשומה מקומית להשלמה.

תוצאה סופית: 423 חבילות ו־4,992 בדיקות עברו; בדיקות טיפוסים בשורש ובפולס עברו. 28 מצבי תצוגה ברוחבים 320 ו־390 עברו ללא שגיאות רינדור או גלישה אופקית. הסקיצה האחרונה בקובץ `version-quality-concept.png` נוצרה בכלי יצירת תמונות ואינה צילום מסך.

בדיקת התיעוד נשארה עם אותם 107 קישורים חסרים קיימים, ללא תקלה חדשה.
