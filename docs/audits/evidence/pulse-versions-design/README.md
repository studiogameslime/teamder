# עיצוב גרסאות ושלוש לשוניות משימות

שינוי מקומי בלבד; אין בנייה, התקנה, פריסה או כתיבה לייצור. הוראות המסירה הקיימות נשמרו, ומסירה מקומית ב־handover-pending.json כוללת שלושה משפטים בעברית. אין לטעון שסומנה משימת ייצור ללא מזהה פריט וחיבור מאומת.

קוד מסך הגרסאות מציג סקירה, משתמשים ושינויים. רשימת הגרסאות נטענת יזום ומשותפת לסקירה ולמשתמשים; שינויים בחיפוש, בסינון ובמערכת ההפעלה אינם קוראים מהמסד. ספירת המשתמשים היא לפי הדיווח העדכני ביותר במערכת הנבחרת, עם כשל קריאה וחוסר דיווח בנפרד. גרסה בחנות אינה בהכרח זמינה לכל המשתמשים או עדיין מותקנת אצלם.

הצילומים מרינדור דפדפן של רכיבי המסך עם נתוני הדגמה וסמלים חלופיים. זו אינה בדיקה במכשיר אמיתי. נבדקו שלוש לשוניות משימות, סקירה, משתמשים, חיפוש, החלפת מערכת, סינון ללא מידע, אימוץ ושינויים ברוחבי 320 ו־390. חסר מידע וכשל קריאה נכללו בנתוני ההדגמה.

עברו בדיקות הטיפוסים של פולס ושל היישום הראשי, וכל 425 חבילות הבדיקה ו־5,002 הבדיקות. 16 מצבי דפדפן עברו ללא שגיאות ריצה או גלישה אופקית. בדיקת התיעוד מצאה 107 קישורים חסרים קיימים, ללא תקלות חדשות ביחס לסבב הקודם.
