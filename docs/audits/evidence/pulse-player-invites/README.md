# מחזורים והזמנות בכרטיס השחקן

שינוי תצוגתי בלבד. מקור הנתונים: `UserActivity.referralCount`, `inviteClicks`, `failedSources`, `limitedSources`. לא נוספו קריאות או כתיבות לייצור. נבדקו תצוגת הסקירה והגישה לפירוט הקיים ב־320 וב־390 פיקסלים, עם נתוני הדגמה (חבר אחד וחמש לחיצות). אין טענת בדיקת מכשיר או הפצה.
