# ראיות השלמת מבנה הפולס — 18.10.2026

השינויים מקומיים על בסיס המאגר, ללא בנייה או פריסה. `preview-build.cjs` מרנדר קוד TSX אמיתי דרך React Native Web. הנתונים מדומים, הרשת החיצונית חסומה והכתיבות המדומות מחזירות כישלון. הסמלים מוחלפים בעיגולים; אזורים בטוחים מוחלפים בערכי אפס. אין להסיק מהבדיקה על Android או iOS.

להרצה: התקנת esbuild, react, react-dom ו־react-native-web בתיקיית `/tmp/pulse-preview`; הפעלת סקריפט הבנייה משורש המאגר; שרת מקומי על 8765 המגיש את אותה תיקייה; הפעלת `workflows-capture.cjs` עם Playwright ודפדפן Chromium. נתיבי הספריות בסקריפטים מתאימים לסביבת הבדיקה הזו.

`results.json` מתעד מסך, מצב, רוחב, שגיאות רינדור וגלישה אופקית. נבדקים פתיחת לשוניות, מעבר בשלבי קמפיין ושמירת כותרת הטיוטה, פתיחת שיחה וכלי תשובה. לא הופעלו כפתורי שליחה, שינוי סטטוס, מחיקה או מתגי מערכת. צילום הדיווח שבנתוני ההדגמה הוא צילום של מסך הדגמה קודם, ולא צילום משתמש אמיתי.

הצילומים נשמרים תחת `docs/features/screenshots/pulse-workflows-*` עם חותמות במניפסט. נבדקו חזותית כיווניות, סיכום קמפיין, סקירה, גרסאות, מדדים, הגדרות וחלון שיחה. צילום חלון שיחה ממתין לסיום הנפשת הכניסה כדי לא להציג שדה כתיבה מחוץ לתמונה באמצע ההנפשה.

בדיקות קוד: `npx tsc --noEmit`, `npx tsc --noEmit -p pulse/tsconfig.json`, `npx jest --runInBand`. התוצאות המלאות נשמרות לצד המסמך.

מגבלות: `adb` ו־`emulator` אינם זמינים כאן. מקלדת מערכת, מחוות, אזורים בטוחים וגלילה במכשיר אמיתי לא אומתו. הוכנה רשומת שחרור מקומית בלבד; ללא חיבור ניהול ייצור מאומת אי אפשר לעדכן את `appConfig/releaseLog` או להעלות צילומים ל־`releaseShots`.

תוצאה סופית: 422 חבילות ו־4,978 בדיקות עברו; בדיקות הטיפוסים בשורש ובפולס עברו. 58 מצבי תצוגה ב־13 מסכים, ברוחבים 320 ו־390, הסתיימו ללא שגיאות רינדור או גלישה אופקית. בדיקת התיעוד מציגה 107 קישורים חסרים קיימים, זהים לראיות השלב הקודם, ללא כשל חדש.

`interaction-results.json`: עברו גם שמירת טיוטת קמפיין במעבר לרשימה ובחזרה, היעדר שליחה בשלב הקהל, יציאה רק בלשונית החשבון, ניווט מדיווח עם אוסף ומזהה מדויקים, חיפוש מחזור לפי מועדון, שדה כתיבה בתוך גובה המסך ושימור טיוטת תשובה בפתיחה וסגירה של הכלים. זיהוי כפתור הכלים מתיר את הסמל החלופי בשם הנגיש; לא נעקפה בדיקת הנראות ולא בוצעה לחיצה מאולצת.
