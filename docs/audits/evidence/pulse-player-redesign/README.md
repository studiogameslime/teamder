# כרטיס שחקן חדש

קוד מקומי בלבד. הצילומים משתמשים ברכיבים האמיתיים דרך רינדור דפדפן, נתוני הדגמה וסמלים חלופיים. אין קריאות או כתיבות לייצור. בדיקות הלוגיקה משתמשות במדיניות הערב האמיתית ובקורא הנתונים. תיעוד Expo 56 באתר הרשמי לא היה נגיש ממדיניות הרשת בסביבה; לא נוספו ספריות או ממשקי Expo. יומן השחרור מוכן מקומית ולא הועלה.

כל 424 חבילות הבדיקות ו־4,996 הבדיקות עברו. בדיקות הטיפוסים של פולס והשורש עברו.
