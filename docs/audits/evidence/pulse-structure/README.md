## שחזור תצוגת הדפדפן

כלי העזר `preview-build.cjs` ו־`preview-capture.cjs` מרנדרים את קוד המסכים עם שירותים מדומים, סמלים חלופיים וכתיבות כבויות. אינם יישום הפולס המקורי. בהרצה מסביבת העבודה הנוכחית נדרשים `esbuild`, `react-native-web@0.21.0`, `react@19.2.3` ו־`react-dom@19.2.3` תחת `/tmp/pulse-preview/node_modules`, וכן Chromium ו־Playwright. קובצי התלויות של המוצר לא שונו.

מריצים את כלי הבנייה משורש המאגר, מגישים את `/tmp/pulse-preview` בשרת מקומי על `127.0.0.1:8765` ומריצים את כלי הצילום. כלי הצילום כולל נתיבי סביבת הענן `/workspace/teamder` ואת מיקום Playwright בה; בסביבה אחרת יש להתאים אותם. בקשות דפדפן חיצוניות נחסמות בכלי הצילום. אין שימוש בחשבון בדיקה חי, שליחת הודעות או יצירת משתמשים.
