# הסרת כרטיסים מפולס

שינוי תצוגה בלבד בשני רכיבים. אין מחיקת נתונים או שינוי שאילתות. שמונה מצבי דפדפן ברוחבי 320 ו־390 עברו בדיקת היעדר כרטיסים, שגיאות וגלישה אופקית. נתוני ההדגמה כוללים במכוון כרטיסים בסיכום, בשדות מקוננים ובציר הזמן. הסמלים הוחלפו בצילום; אין בדיקת מכשיר אמיתי או גישה לייצור.

בדיקות TypeScript של פולס והשורש עברו; יומניהן ריקים בהצלחה. רישום השחרור מוכן מקומית בלבד.

כל 423 חבילות הבדיקה ו־4,992 הבדיקות עברו. בדיקת התיעוד מצאה 107 קישורים חסרים קיימים, ללא תקלות חדשות ביחס לראיות הקודמות.
