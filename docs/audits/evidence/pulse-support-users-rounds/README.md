כיסוי: רשימת תמיכה ושיחה; עמוד משתמשים ראשון ושני, חזרה ללא קריאה, חיפוש שרת, כשל בעמוד הבא וניסיון חוזר; רשימת מחזורים והעברת מזהה לנתיב פרטים; סקירת מחזור, שחקנים ודירוגים, מידע לשחקן, הגדרות, כרטיסים, תוצאות ישנות והיסטוריה מאושרת, וכשל בטעינת פרטי המחזור.

שינויים במיון וחיפוש המשתמשים: המיון החדש הוא לפי `lastSeenAt` שב־Firestore, ולא לפי רענון חשבון ההתחברות שדרש סריקת כל החשבונות. החיפוש מוגבל לתחילת שם או דוא״ל ומסודר לפי שדה החיפוש. עיון לפי מזהה כולל גם חשבונות ללא פעילות, בדיקה ומחיקה. אין ספירת עמוד שמוצגת כסך כל המשתמשים.

פרטי מחזור: המידע נקרא רק בפתיחת המחזור ומקבל מטמון קצר; קריאות שחקנים מדורגות במקביל עד שש. ההיסטוריה המאושרת וסטטיסטיקות הערב מוצגות בנפרד מהרשומות הישנות. כרטיסי מועדון אינם מיוחסים למחזור בלי ראיה. כשלים וחלונות בני 500 מוצגים במפורש כחסרים/חלקיים.

הבדיקה המלאה הראשונה גילתה בפונקציית קריאת אוסף פנימי שימוש בכתובת HTTP במקום מזהה מסמך Firestore. תוקן למזהה הקנוני; נבדק מחדש. לא בוצעו בנייה מקורית, פריסה, שינוי הרשאות או כתיבה לייצור.
