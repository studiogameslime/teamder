# מסכי כניסה קודמים וכלי פיתוח מוסתרים — הסבר קצר

האפליקציה שומרת גם מסכי הדרכה ישנים וכלי ניסוי שאינם מוצגים בשימוש הרגיל. הדמות הניסיונית ומעבדת האנימציות אינן חלק מהמסך הרגיל למשתמש.

ב־10.10.2026 נוספה רשימה מפורשת של רכיבים ישנים שנשמרים מחוץ לאפליקציה הפעילה, כדי שלא יתבלבלו בינם לבין המסכים העדכניים. לא הופעלו מסכים ישנים ולא נמחקה תאימות למשתמשים.

ב־8.10.2026 נוסף קיצור בדיקה לסיכום אישי ללא הישגים מיוחדים. הוא משתמש בנתוני דמו בלבד ואינו מסך נוסף למשתמשים.
