# שיחה עם המועדון, המחזור או חבר

## תיעוד כשלים — 20.10.2026

נוסף תיעוד אוטומטי לנקודות כשל במסלול הזה, עם מקור התקלה. הפעולה המקורית שומרת על ערכי החזרה והודעות השגיאה שלה. השינוי מקומי, טרם הופץ, ואין אימות מסירה חיה לפולס.

[דוח דיווח השגיאות והראיות](../../changes/2026-10-20-error-reporting-audit.md).

אפשר לדבר עם חברי המועדון, עם השחקנים הרשומים למחזור או בפרטי עם חבר. מי שנמצא רק ברשימת ההמתנה אינו משתתף בשיחת המחזור.

אחרי סיום מחזור מוצג שעון שמראה כמה זמן נשאר לכתוב. אחרי 24 שעות, או מיד כשמחזור מבוטל, ההודעות נשמרות לקריאה בארכיון. אם מסירים חברות, הכתיבה הפרטית נעצרת וההיסטוריה נשמרת לפי הרשאות הקריאה.
