# שיחה עם הקבוצה או עם חבר

## עדכון מקומי — 10.10.2026

בטעינת שיחה אפשר תמיד לחזור אחורה. כשל זמני בפתיחת שיחת מחזור מקבל ניסיון חוזר; מחזור שאינו זמין מקבל הודעה נפרדת.

התנהגות הכשל נבדקה בקוד מבודד; לא הורצה במכשיר מול הנתונים האמיתיים.

בסקירה נמצאה חולשת גישה בשיחה פרטית. באישור הבעלים הוחל מקומית תיקון שמקבע את שני המשתתפים ואינו מאפשר להעניק לאדם שלישי גישה באמצעות שינוי הרשימה. שיחות קיימות ופתיחה חדשה נשארות מיועדות לשני הצדדים המקוריים. התיקון נבדק באמולטור מסד, ומבנה42 השיחות הקיימות נמצא תואם בלי לקרוא הודעות. התיקון נפרס באישור מפורש ב־10.10.2026, והכללים החיים אומתו מול הקובץ שנבדק.


אפשר לדבר עם חברי המועדון, עם משתתפי מחזור או בפרטי עם חבר. לכל שיחה יש קהל משלה, ולכן הודעה שנשלחת לקבוצה אינה מופיעה אוטומטית בשיחה אחרת.
