# הכרעת תיקו ופנדלים — הסבר פשוט

אחרי תיקו אפשר להכריע בפנדלים. המנהל בוחר בועט ושוער ומסמן אם הבעיטה נכנסה או הוחמצה. התוצאות נשמרות בנפרד משערי המשחק הרגילים.

[להסבר המעמיק ולמפת הקוד](penalties.md)

## תיקוני סבב הבאגים — 8.10.2026

בעיטה מופיעה בלוח רק אחרי שהשמירה אושרה. אם השמירה נכשלת אפשר לנסות שוב בלי ליצור בעיטה כפולה. ביטול בעיטה מוודא שלא נוספה בינתיים בעיטה אחרת.

![שמירת בעיטה אחת בדמו](../screenshots/audit-fix-Shootout.jpg)

בדמו: 2:2, פתיחת פנדלים, אלין בועט מול רון, סימון נכנס; הלוח חזר עם בעיטה אחת ושער אחד לאדומים. כשל שרת וניסיון חוזר נבדקו מבודד בלבד. לא סוים מחזור אמיתי.
