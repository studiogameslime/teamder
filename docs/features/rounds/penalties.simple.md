# הכרעת תיקו ופנדלים — הסבר פשוט

אחרי תיקו אפשר להכריע בפנדלים. המנהל בוחר בועט ושוער ומסמן אם הבעיטה נכנסה או הוחמצה. התוצאות נשמרות בנפרד משערי המשחק הרגילים.

[להסבר המעמיק ולמפת הקוד](penalties.md)
