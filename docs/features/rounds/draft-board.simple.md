# לוח בחירה, החלפה ופרסום קבוצות — הסבר פשוט

הקפטנים בוחרים שחקנים בתורות עד שמתקבלות הקבוצות. אפשר לחזור לחלוקה קיימת ולתקן אותה בהתאם להרשאה. שמירת החלוקה אינה פרסום שלה לכל השחקנים.
