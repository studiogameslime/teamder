# הפיכת מחזור חד־פעמי למועדון — הסבר פשוט

אחרי מחזור חד־פעמי אפשר להפוך את הקבוצה למועדון. המארגן נותן שם ובוחר אילו משתמשים להזמין. הפעולה ממשיכה את הקבוצה הקיימת ולא מחייבת ליצור מחזור חדש.

[להסבר המעמיק ולמפת הקוד](promote-orphan.md)

## צילום והיקף ההוכחה

לא נאסף צילום תקף לפעולה הזאת. ההסבר נשען על הקוד; תנאי הבדיקה והמגבלות מפורטים במסמך המעמיק.
