# עריכת מחזור וסדרה — הסבר פשוט

מארגן יכול לשנות את פרטי המחזור, המקום והגדרות ההרשמה. כששינוי חשוב נוגע לשחקנים שכבר נרשמו, מופיע אישור לפני ההודעה אליהם. שינוי מחזור יחיד והפסקת סדרה הם פעולות שונות.
