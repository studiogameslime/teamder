# ממלאים, השאלה ורוטציה — הסבר פשוט

אם חסר שחקן לקבוצה שעל המגרש, המנהל יכול לבחור ממלא. מילוי זמני משאיל שחקן; מילוי קבוע משנה את הקבוצה שלו. זה שונה מהזמנת שחקן חדש מהאזור למחזור.
