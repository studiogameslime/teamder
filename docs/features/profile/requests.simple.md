# בקשות הצטרפות ואישורים

בכניסה מהפעמון בבית רואים בקשות חברות ובקשות הצטרפות למועדונים ולמחזורים שאתם מנהלים. כניסה מתפריט מועדון פותחת את אותו מסך, כשהוא מסונן מראש למועדון הזה ולמחזורים שלו. אפשר לבחור מועדון אחר או לחזור לכל המועדונים.

כל בקשה מופיעה בכרטיס קומפקטי עם תמונת השחקן, שמו, ההקשר וכפתורים לפרופיל, אישור ודחייה. כפתורי האישור והדחייה בצד ימין, וכפתור הפרופיל בצד שמאל. אפשר למיין לפי שם השחקן. מונה הבקשות מתייחס רק לרשימה שמוצגת לפי הסינון. בקשה ללא תאריך לא מציגה זמן משוער.

כשל טעינה מציג אפשרות לנסות שוב; בזמן החלטה הכפתורים נעולים. אישור כמה בקשות יחד דורש אישור נוסף ומציג גם כישלונות חלקיים.
