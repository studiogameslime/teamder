# דיווח תקלה והצעת שיפור

## תיקון פערי העונות — 20.10.2026

השינוי בקובץ השרת המשותף במסגרת תיקוני העונות נוגע לשער הסגירה, אימות מחזור והשלמת סטטיסטיקה בלבד. נתיבי הפיצ׳ר המתועדים כאן לא שונו בסבב זה. הבדיקות המלאות עברו; אין בכך אימות חדש של פריסה או שירות חיצוני.

[דוח תיקונים, בדיקות ומגבלות](../reviews/2026-10-20-seasons-fixes.md).

שני הכפתורים בתפריט נשארו: כל אחד פותח את הלשונית המתאימה במסך החדש. אפשר לעבור בין הלשוניות בלי לאבד את המלל או את התמונה שכבר צורפה.

כותבים מה קרה או מה רוצים לשפר, ואפשר לצרף צילום מסך וללחוץ עליו כדי לסמן. פרטי התקלה הטכניים מצורפים אוטומטית. אפשר להחליף או להסיר את התמונה; אם השליחה נכשלת, הטיוטה נשמרת לניסיון חוזר כל עוד נשארים במסך.
