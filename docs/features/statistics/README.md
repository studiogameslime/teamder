לכל שינוי מספרי יש לבדוק: האם היחידה היא מחזור או משחקון; האם החלון הוא עונה, ארכיון או כל השנים; האם היעדר מידע הומר לאפס; האם השם/הצמד מוגבלים למועדון; ומה קורה אחרי סגירת עונה. טקסט בתוך צילום הוא חלק מממשק, לא מקור אמת למספר.

מקורות עיקריים: `communityStats`, `communityPlayerStats`, `communityPairStats`, `roundSummaries`, ארכיוני עונה; נתונים אישיים גלובליים משתמשים גם ב־`users`, `playerStats` ו־`pairStats`. אין לערבב מקורות אלו רק מפני ששדותיהם בעלי שמות דומים.

את כללי הפעלת וסגירת העונה ראה ב[עונות](../clubs/seasons.md). מדף תארים בפרופיל הוא [מסך תארים](../profile/season-titles.md). המקורות הישנים וההמלצות מופרדים ב[סקירת התחום](../reviews/clubs-stats-chat.md).
