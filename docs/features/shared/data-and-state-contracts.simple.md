## קיצור המתנה למידע, 4.11.2026

כשכמה אזורים מבקשים בו זמנית את אותו סגל, אותו שם שחקן או את דירוגי אותו מועדון, הבקשות חולקות את הקריאה שכבר מתבצעת. לאחר שהקריאה מסתיימת, ביקור חדש קורא מידע מחדש. חשבונות שונים נשארים מופרדים, ושמירת פרופיל או דירוג משחררת בקשות ישנות מהשיתוף.

חישוב הסטטיסטיקה יכול להתחיל יחד עם טעינת הפרופיל, והמספרים מוצגים רק אחרי שהגיעו הסכומים המעודכנים. בבדיקה מדומה של טעינות אטיות התקצרה ההמתנה מ-1000 ל-600 אלפיות שנייה; בשלוש בקשות זהות במקביל בוצעה קריאה אחת במקום שלוש. 19 בדיקות השינוי עברו, אך זו אינה מדידת טלפון או הבטחה לאחוז שיפור קבוע. השינוי מקומי וטרם הופץ.
