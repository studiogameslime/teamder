# שער כניסה מאובטח לפולס

## תיעוד כשלים — 20.10.2026

נוספו תצפיות דיווח בנקודות הכשל של המקורות המשויכים לפיצ׳ר, במסגרת הרחבה רוחבית. נשמרו ערכי החזרה, הזריקות ותנאי הפעולה הקיימים; נוסף מקור קוד והקשר לדיווח. כיסוי תחבירי אינו הוכחת הרצה של כל מצב. השינוי מקומי וטרם הופץ; בדיקות המסירה, מגבלות מניעת הכפילויות והמסלולים שטרם חוברו מתועדים בדוח המשותף.

[דוח דיווח השגיאות והראיות](../../changes/2026-10-20-error-reporting-audit.md).

[הסבר פשוט](pulse-security.simple.md)

`pulse/src/screens/AdminLoginScreen.tsx` הוא שער חדש לפני `AuthenticatedApp`. הסשן מאומת ב־pulseAdminProxy, עם רשימת מנהלים מדויקת, אסימון Firebase שלא בוטל ומדיניות יעדים מוגבלת. הרשאות השירות נשארות בשרת.

[מסלול הנתונים, מצבי הסשן, ההגדרות, המעבר והבדיקות](../../../pulse/docs/secure-access.md).

מסך חדש זה לא הורץ או צולם. אין ראיה חזותית עדכנית; מפת הכיסוי מציינת זאת במפורש, ולא נוסף צילום שאינו קיים למניפסט.
