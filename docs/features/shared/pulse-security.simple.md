# כניסה מאובטחת לפולס

פולס יאפשר כניסה רק לחשבון מנהל שאושר מראש. מפתחות שירות יישמרו בשרת והטלפון ישמור התחברות מוצפנת.

הוכן מקומית בלבד, לפני הגדרות שרת ובנייה חדשה. מסך הכניסה לא צולם ולא אומת במכשיר.
