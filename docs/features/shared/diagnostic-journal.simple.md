# רצף פעולות לצורך שחזור תקלות — הסבר פשוט

האפליקציה שומרת במכשיר את סדר הפעולות מאז פתיחתה: אילו מסכים, מחזורים ומועדונים נפתחו, לחיצות, מעבר בין לשוניות וגלילות. הפעולות אינן נשלחות בפני עצמן. כששולחים דיווח או נרשמת שגיאה, מצורף לרישום הקיים הרצף הרלוונטי כדי לעזור לשחזר את התקלה.

לא נשמרים טקסט שהוקלד, תוכן הודעות או סיסמאות. יציאה מהחשבון או החלפתו מנקות את התיעוד המקומי. שגיאה שנשמרה במכשיר ולא נשלחה תוכל להישלח בפתיחה הבאה, באותו חשבון בלבד.

ליומן יש מגבלת גודל. בשימוש ממושך מאוד נשמרים תחילת הרצף וסופו, ומצוין כמה פעולות הושמטו. סגירה פתאומית של תהליך הטלפון עלולה להקדים את השמירה; אין הבטחה לתיעוד כל קריסה של מערכת ההפעלה.

בפולס מופיעה אפשרות לפתוח את רצף הפעולות מתוך דיווח או שגיאה. אפשר לסנן לפי סוג פעולה, לראות זמן, מסך ומזהי מחזור ומועדון, ולהעתיק את הרצף לצורך שחזור. אם חלק מהפעולות הושמטו, הדבר מוצג במפורש. דיווחים ישנים אינם מקבלים רצף שלא נשמר בזמן אמת.

בדיקת שליחה אמיתית מחשבון מחובר לפולס נדחתה לבקשת הבעלים; היא עדיין לא אומתה. [הפירוט הטכני, הכיסוי ומגבלות השחזור](diagnostic-journal.md).
