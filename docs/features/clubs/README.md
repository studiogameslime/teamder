## לפני שינוי

1. קרא `AGENTS.md` ואת המסמך הממוקד כאן.
2. בדוק את המסך, השירות והממיר הנוכחיים; תאריך המסמך אינו תחליף לקריאת ההפרש מאז הקומיט הרשום.
3. הפרד מנהל, יוצר, חבר, מבקש ואורח. בדיקת תצוגה בנתוני דמה אינה בודקת הרשאות.
4. בדוק מסכים משותפים בכל מחסניות הניווט שאפשר להגיע מהם.
5. אל תבדוק מחיקה, עזיבה, הוצאת חבר או סגירת עונה בחשבון הייצור שעל האמולטור.
6. עדכן את המסמך, טבלת המצבים והצילום לאחר שינוי. הפנה לצילום חדש וכתוב באיזו סביבה צולם.
