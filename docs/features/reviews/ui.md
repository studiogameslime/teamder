# הצעות לנראות

הצעות בלבד; מקור המיפוי `8e8fde5`. השפה הרצויה נשענת על הכחול של האפליקציה, לבן, ירוק למצבי אישור, אייקונים עקביים ותנועה קצרה. אין צורך להפוך כל מסך לצבעוני יותר.

| אזור | הצעה | מה לשמר |
|---|---|---|
| תפריטים | להשלים את אותה שפה לחלונות שנותרו, כולל ידית פעילה ומרווחי שורה | הרשאות הפעולות, גלילה וסגירה בכפתור חזרה |
| כרטיסי היסטוריה | תאריך בולט, תג השתתפות ושתי שורות מדדים מיושרות | גובה אחיד, כיווניות וסימני אפס אמיתיים |
| רשימת שחקנים | אותו מיקום לתמונה, שם, מצב ופעולות | הבחנה בין משתמש, אורח וממתין |
| סטטיסטיקה | עקביות בכותרות, ציון התחום ובחירת העונה | יחידות ומכנים; נתון חסר אינו אפס |
| מסך חי | היררכיה של ניקוד, זמן, קבוצות ופעולה ראשית | מקום קבוע לפעולות והבדל בין מצב רגיל למתקדם |
| פנדלים | לשמר סמלי גול/החמצה ולהקפיד על ניגודיות גם בלי אנימציה | התוצאה האמיתית, תור ושוער/בועט |
| תמונות מועדון | לשמור סדר ומשמעות מזהים ולהציג בחירה בצורה עקבית | תמונות קיימות של המשתמש; לא להחליף מזהים ישנים |
| קרוסלת הבית | גובה קטן, טקסט לכל הרוחב ונקודות פשוטות | ללא מונה ״1 מתוך 7״; בלי פס קישוט שאינו תורם |
| מצב שגיאה | סמל והסבר קצר עם ניסיון חוזר במקום שטח ריק | אין להציג טקסט טכני למשתמש רגיל |

כל שינוי דורש צילום של המסך המרונדר, כולל שם ארוך, מלל לטיני, גופן גדול ורשימה ארוכה. אייקונים מימין לפי סדר הקריאה; אין לתקן באמצעות row-reverse. קו בידית אינו הבטחה לגרירה אם המחווה אינה ממומשת.

צילומי המפה הם נקודת התחלה לדיון. לפני החלפה גורפת יש לאשר סקיצה של רכיב אחד ולבדוק את אותה שפה במסכים צפופים ובמצבי הרשאות שונים.
