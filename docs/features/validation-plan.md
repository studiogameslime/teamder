# תוכנית אימות מבוקרת

## שלב שהושלם

מיפוי קוד לפי מסכים ושירותים, סקירת הטקסט הנגיש ב־137 מקורות היסטוריים, בחינת עמודי התמונות, וצילומי מצבי דמו באמולטור אנדרואיד. מקורות חופפים נבדקו באמצעות התאמת טקסט וקריאת ההבדלים; לא נטען שהם קבצים זהים. צילומים זעירים שלא מאפשרים לקרוא כל פרט מסומנים בסקירות.

## השלמת בדיקות מצבים

| מסלול | מה לבדוק | סביבת אימות |
|---|---|---|
| כניסה והזמנה | התקנה חדשה, אורח, ספקי התחברות, חידוש פעולה פעם אחת | חשבון בדיקה קיים; מכשיר עם ספק זמין |
| מחזור | הרשמה, מלא, המתנה, אישור, ביטול, הצטרפות חוזרת | נתוני בדיקה; לא החשבון האמיתי |
| ניהול | שינוי סגל, חלוקה, סיום משחק, פנדלים, סיום ערב | נתוני בדיקה מבודדים |
| מסד | שדה חסר/אפס/ריק, ממירים, תגובת סשן ישן | קריאה אמיתית ומבחני שירות |
| תקשורת | ניתוק, כשל, רענון, חזרה מרקע, הודעות | שני משתמשי בדיקה קיימים |
| חזות | טקסט ארוך, כיווניות, מקלדת, גלילה, גודל גופן | אנדרואיד ומערכת אפל; צילומי כל מצב |
| תנועה | תנועה מופחתת, הקשות חוזרות, יציאה באמצע | מכשיר חלש ובנייה חתומה |
| רכיבים מקוריים | הרשאות, התראות, בריאות, שעון ורכיבי בית | מכשירים תואמים; הרשאות אמיתיות |

לכל בדיקה שומרים קדם־תנאים, צעדים, ציפייה, תוצאה, קומיט וצילום. כשל בכלי פתיחת המסלול אינו מוכיח כשל בניווט הרגיל. תוצאה חסרה נשארת ״לא נבדק״. אין לבצע פעולות הרסניות או להמציא חשבון כדי למלא את הטבלה.
