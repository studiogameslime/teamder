# קרוסלת הידעת — הסבר קצר

בקרוסלת הידעת מופיעים משפטים קצרים על הדברים שכדאי להכיר באפליקציה. אפשר להחליק, לבחור נקודה או ללחוץ על הטיפ כדי להגיע לפיצ׳ר.
